# Held-out bot-style command lines for the fidelity check.
#
# Written after the fixes driven by corpus.txt, and run against the honeypot
# once, unchanged, for the number in the README. Same format and rules as
# corpus.txt. Lines whose answer depends on the machine profile, on systemd,
# or on the container itself (pid 1, no network devices) are left out.

## persistence

## miner set-up
