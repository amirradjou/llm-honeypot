# Bot-style command lines for the fidelity check.
#
# Hand-written in the shape of what SSH bots commonly send after logging in
# (recon one-liners, key planting, Mirai-style busybox probes, miner set-up,
# clean-up) plus the shell syntax those lines lean on. Each line runs once in
# the honeypot and once in a fresh Ubuntu 22.04 container, and the two results
# are compared.
#
# Format: "## family" starts a group; every other line is "<mode><TAB><command>".
#   same   exit code matches, and stdout/stderr are empty or non-empty on both
#   exact  as "same", and stdout matches byte for byte
#   net    needs the network: run on the honeypot only and checked for giveaways
#          (the reference box has no network, so a comparison means nothing)
